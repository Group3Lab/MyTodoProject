# MyTodo

控制台待办任务管理程序（课程作业）。把「一条任务」抽象成类，用短小的函数实现增删改查、筛选统计与报告导出，并用 Git 做版本管理。

## 一、作业目标

| 能力                | 要求                                                   |
| ------------------- | ------------------------------------------------------ |
| 类与对象            | 把「一条任务」抽象成一个类，属性放在类里，行为写成方法 |
| 函数                | 把功能拆成短小的函数，参数与返回值用得对不对           |
| 列表                | 遍历、增删、按条件筛选、排序                           |
| 字符串              | 拼接、切分、比较、格式判断                             |
| 流程控制            | 循环与分支写得对不对，边界情况考虑没考虑               |
| 输入健壮性          | 面对乱入输入，程序不崩溃                               |
| 团队协作            | 先定接口再分头写，最后拼成一个完整程序                 |
| 版本管理            | 会用 Git 给自己的代码存档，每次更新都提交              |
| 附加 · 图像处理入门 | 用 OpenCV 创建图像、画图形、写字、保存文件             |

## 二、作业要求

程序采用**控制台菜单循环**，包含：添加任务 / 查看全部 / 标记完成 / 删除任务 / 搜索筛选 / 统计 / 导出报告 / 保存 / 退出。

### 必做功能

1. **添加任务**：输入标题、优先级（高/中/低）、截止日期；标题为空要提示，日期格式不对要重问。
2. **查看全部**：每条显示编号、优先级、截止日期、状态、标题；清单为空时给出提示，而不是什么都不显示。
3. **标记完成**：选一个编号，把任务标记为已完成。
4. **删除任务**：选一个编号，删除前要二次确认。
5. **搜索与筛选**：只看未完成、只看已完成、只看已逾期、按关键字搜索、按优先级排序查看、按截止日期排序查看。
6. **统计**：任务总数、已完成数、未完成数、已逾期数、完成率。
7. **数据保存**：启动时自动读取上次的数据，退出时自动保存；重新打开程序数据还在。
8. **导出报告**：把当前清单导出成一个文件，双击就能打开、一眼看出任务情况。
   - 顶部：生成日期、任务总数、已完成数、完成率、完成率进度条
   - 中间：明细表格（编号、优先级、截止日期、状态、标题）
   - 已逾期的任务要标红
   - 文件名带日期，例如 `report_2026-09-28.html`
9. **输入健壮性**：输入字母、超大数字、直接回车，都不能让程序崩溃或出现报错信息。

### 附加任务：用 OpenCV 生成任务统计图

读取当前任务清单，生成一张 PNG 图片，用图形直观展示任务分布：

- 排条形图，分别显示「高 / 中 / 低」三个优先级的任务条数
- 图上有标题、日期、数字标注
- **图上的数字必须与清单里的真实数据一致，不能写死在代码里**
- 保存成 `chart.png`，双击能打开查看

要接触的 OpenCV 知识点：创建空白图像、坐标系统（左上角是原点）、画矩形、写文字、颜色顺序、保存图片。

## 三、注意事项

1. 一条任务 = 标题 + 优先级 + 截止日期 + 是否完成，存成一行文本：

   ```
   写高数作业 | 高 | 2026-10-08 | 未完成
   ```

   文件存储、屏幕显示、读取解析都用这一种格式。

2. 日期统一写成 `YYYY-MM-DD`（月、日不足两位补 0）。这样比较日期早晚直接比字符串大小。
3. 标记完成和删除，一律使用「查看全部」里的编号。筛选和排序结果只用于查看，不用于操作，避免认错任务。
4. 关于 AI
   - 用 AI 写出来的代码，组里必须有人能解释清楚每一行在做什么
   - 必须能当场按要求改动代码
   - 提交时如实说明哪里用了 AI、自己改了什么

## 数据格式

每条任务一行，字段用 `|` 分隔：

| 字段     | 示例       | 说明              |
| -------- | ---------- | ----------------- |
| 标题     | 写高数作业 | 不能为空          |
| 优先级   | 高         | 高 / 中 / 低      |
| 截止日期 | 2026-10-08 | 固定 `YYYY-MM-DD` |
| 是否完成 | 未完成     | 未完成 / 已完成   |
