# 添加新功能指南

本文档面向组员，说明如何在现有架构下添加新的菜单功能。

## 一、架构概览

```
MyTodo/
├── core/
│   ├── menuModule/          # 菜单系统（已完成，无需修改）
│   │   ├── menu.py          # 菜单抽象基类
│   │   ├── menuSystem.py    # 菜单管理系统
│   │   └── menuFactory.py   # 菜单工厂（需要在这里注册新菜单）
│   └── taskModule/          # 任务系统（已完成，可扩展）
│       ├── task.py          # 任务数据模型（数据结构负责人，这里是要长期更改的地方）
│       ├── taskSystem.py    # 任务管理系统（数据结构负责人，这里是要长期更改的地方）
│       └── taskSL.py        # 数据存取（data/tasks.json 的保存与读取）
├── Menus/                   # 具体菜单实现（你的工作区）
│   ├── AddTaskMenu.py       # 添加任务
│   ├── ViewTasksMenu.py     # 查看任务
│   ├── MyDeleteTaskMenu.py  # 删除任务
│   └── ...                  # 其它功能菜单
└── src/
    └── main.py              # 主程序（无需修改）
```

> **目录名注意**：实际目录是 **`Menus/`（首字母大写）**，导入也写 `from Menus.XXX import XXX`。Windows 大小写不敏感所以写错也能跑，但 Linux/CI 上会 `ModuleNotFoundError`，务必按大写写。

## 二、添加新功能的三步流程

### 步骤 1：在 `Menus/` 文件夹创建新菜单类

在 `Menus/` 文件夹下创建一个新的 `.py` 文件，例如 `CompleteTaskMenu.py`（注意目录名 `Menus` 首字母大写，导入时也必须一致）。

**模板代码：**

```python
"""
[功能描述]
使用依赖注入获取 TaskSystem 实例
"""

from core.menuModule.menu import Menu
from core.taskModule.taskSystem import TaskSystem


class YourMenuName(Menu):
    def __init__(self, task_system: TaskSystem):
        super().__init__(
            "菜单名称",           # 显示在主菜单的标题
            "菜单功能简介"        # 显示在主菜单的说明（可以多行）
        )
        self.__task_system = task_system

    def execute(self) -> int:
        """菜单的核心逻辑"""
        try:
            # 在这里实现你的功能
            # 可以使用 self.__task_system 的所有方法
            
            return 0  # 成功返回 0

        except Exception as e:
            print(f"[错误] {e}")
            return -1  # 失败返回 -1 （外部会处理错误码不必担心）
```

**如果新菜单不需要访问数据：** 让 `__init__` 不接收 `task_system`，调用 `super().__init__(...)` 后直接写 `execute()` 即可，注册时也不传参数（见步骤 2）。可参考 [MenuA.py](../Menus/MenuA.py)（该菜单当前未启用，仅作无依赖写法的参考）。

### 步骤 2：在 `menuFactory.py` 注册新菜单

打开 `core/menuModule/menuFactory.py`，做两处修改：

**① 在文件顶部导入你的菜单类**（和已有的导入写在一起，路径同样用大写 `Menus`）：

```python
from Menus.ViewTasksMenu import ViewTasksMenu
from Menus.AddTaskMenu import AddTaskMenu
from Menus.MyDeleteTaskMenu import MyDeleteTaskMenu

from Menus.YourMenuName import YourMenuName  # 添加这一行
```

**② 在 `_register_menus()` 方法中注册**（注意注册顺序就是实际菜单显示顺序）：

```python
@staticmethod
def _register_menus(menu_sys: MenuSystem, task_system: TaskSystem) -> None:
    # 功能菜单
    menu_sys.register(ViewTasksMenu(task_system))
    menu_sys.register(AddTaskMenu(task_system))
    menu_sys.register(MyDeleteTaskMenu(task_system))
    menu_sys.register(YourMenuName(task_system))  # 添加这一行
```

> 不需要访问数据的菜单（如原来的 `MenuA`）直接 `menu_sys.register(YourMenuName())`，不传 `task_system`。

### 步骤 3：自测

在项目根目录运行程序：

```bash
python src/main.py
```

你的新功能会自动出现在菜单列表中。改完记得跑一遍自动化测试（见 [测试指南](./测试指南.md)）：

```bash
python run_tests.py
```

## 三、TaskSystem 提供的方法

你可以在菜单的 `execute()` 方法中使用 `self.__task_system` 调用以下方法：

| 方法 | 说明 | 返回值 |
|------|------|--------|
| `add(newTask: Task)` | 添加一条已构造好的任务 | `Task` 对象 |
| `get_by_index(idx: int)` | 获取指定索引的任务（返回内部引用，只读用） | `Task` 对象或 `None` |
| `get_all_tasks()` | 获取全部任务（返回内部列表引用，供筛选/排序） | `list[Task]` |
| `delete(idx: int)` | 删除指定索引的任务 | `bool`（成功/失败） |
| `update_completed(idx, status: bool)` | 修改完成状态 | `bool` |
| `update_priority(idx, priority: Priority)` | 修改优先级 | `bool` |
| `update_due_date(idx, due_date: datetime)` | 修改截止日期 | `bool` |
| `get_task_count()` | 获取任务总数 | `int` |
| `Save()` | 保存到 `data/tasks.json` | `bool` |

**注意：** 索引从 `0` 开始，但用户看到的编号从 `1` 开始，需要转换：`user_input - 1`

**注意：** `_get_by_index()` 是内部方法，返回的是内部引用（可直接改到数据），不要在自己的菜单里调用它。只读数据请用 `get_by_index()`。修改数据请用上面的 `update_xxx` 方法。

**注意：** 添加任务时先用 `Task(标题)` 构造对象，设好 `priority` / `due_date` 再 `add()`；不要让 `TaskSystem` 去解析标题字符串。

## 五、Task 类的属性

当前 Task 对象包含以下属性（都是只读 `@property`，要改走带校验的 setter）：

| 属性 | 类型 | 说明 |
|------|------|------|
| `title` | `str` | 任务标题，非空，创建后不可改 |
| `priority` | `Priority` 枚举 | 高 / 中 / 低，默认「中」 |
| `due_date` | `datetime` | 截止日期 |
| `has_due_date` | `bool` | 是否设过截止日期（只读） |
| `is_completed` | `bool` | 是否已完成，默认 `False` |

`Priority` 枚举来自 `core/taskModule/task.py`，用 `.value` 取中文（`高`/`中`/`低`），用 `.name` 取英文（`High`/`Medium`/`Low`）；**界面显示一律用 `.value`**，保持与其它菜单一致。

## 六、常见问题

### Q1: 菜单编号是如何分配的？
A: 菜单编号由 `MenuSystem` 自动分配，按照注册顺序从 `1` 开始递增。你只需关注注册的先后顺序。

### Q2: 如何获取用户输入？
A: 在 `execute()` 方法中使用 `input()` 函数：
```python
user_input = input("提示信息: ").strip()
```

### Q3: 如何处理非法输入？
A: 使用 `try-except` 捕获异常，并返回 `-1` 表示失败：
```python
try:
    num = int(user_input)
except ValueError:
    print("[错误] 输入无效")
    return -1
```

### Q4: 可以修改 `core/` 目录下的文件吗？
A: 如果需要扩展 `TaskSystem` 的功能（如添加搜索、筛选方法），可以修改 `core/taskModule/taskSystem.py`。但不要修改 `core/menuModule/` 中的文件。

### Q5: 多个菜单可以共享数据吗？
A: 可以。所有菜单通过依赖注入共享同一个 `TaskSystem` 实例，因此在一个菜单添加的任务可以在另一个菜单中看到。

### Q6: 菜单里出现一个叫 `MenuA` 的是什么？
A: 那是组长留的测试菜单（[MenuA.py](../Menus/MenuA.py)），用来验证菜单系统能否正常注册和显示，**目前已在 `menuFactory.py` 中注释掉、不会显示**，不用管它。

### Q7: 改完功能怎么确认没改坏别人？
A: 跑自动化测试：`python run_tests.py`。详见 [测试指南](./测试指南.md)。
